# ADVANCE-WITH-NOTES ledger

Running list of binding considerations issued at G3 (`/brand-review`) with an
ADVANCE-WITH-NOTES verdict. The brand-director checks this ledger at every G3 and at each
weekly review; a note honored on a later item gets marked `[HONORED <item> <date>]`, a note
that keeps being ignored is an audit failure (RUNBOOK §9). Newest first.

Format per entry:
`- YYYY-MM-DD · from G3 of NNN-slug · <the note> · binds: <future item type> · [OPEN]`
