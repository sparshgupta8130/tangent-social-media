# Non-item consults

Consult memos not bound to a pipeline item (naming, platform expansion, monetization
timing, identity questions) live here as `YYYY-MM-DD-<topic>.md` from
`templates/consult-memo.md`. Item-bound consults live in the item's own
`ops/pipeline/NNN-slug/consults/` folder. Routing + protocol: `.claude/skills/consult/SKILL.md`.
