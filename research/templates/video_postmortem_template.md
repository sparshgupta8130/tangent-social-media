# Per-Video Post-Mortem Template (MANDATORY — one file/section per video)

Every analyzed video gets its own complete post-mortem in this exact structure. No section may be
omitted. If a section cannot be filled from available evidence, it must say `DATA GAP: <what's
missing and what was tried>` — never silently skipped, never filled with invention.

## Evidence-tier tagging (required on every substantive claim)

- `[OBSERVED]` — analyst directly saw it: fetched the video page, transcript, caption, comments,
  or embedded player. Strongest tier.
- `[REPORTED]` — from a secondary source (article, Socialblade, another creator's breakdown).
  Must carry a source URL.
- `[INFERRED]` — analyst reasoning from titles/thumbnails/patterns. Must be labeled as inference
  and justified in one sentence.

Presenting `[INFERRED]` material as if it were `[OBSERVED]` is fabrication and voids the dossier.

## VIDEO: <title or first-line hook>

### 0. Identity & stats
- URL, platform, post date (or approx), length
- Views / likes / comments / shares-saves where visible (each with source + as-of date + confidence)
- Rank within creator's catalog (top-N by views? typical? outlier multiple vs channel median?)

### 1. Packaging (the pre-click/pre-swipe layer)
- Title / first caption line, thumbnail or first-frame description
- What curiosity gap or promise is made? Is the payoff named or teased?
- Text overlay on frame 1 (if observable)

### 2. Hook (0–3s)
- Verbatim opening line if obtainable `[OBSERVED via transcript]`, else best evidence
- Hook taxonomy classification (result-first / bold claim / question / negative warning /
  demo-in-motion / "nobody talks about X" / other — per 03_virality_science.md)
- What does the viewer SEE in the first seconds (talking head? screen? finished result?)

### 3. Structure & retention engineering
- Beat map: hook → context → steps/payoffs → close (with rough timestamps if obtainable)
- Open loops planted and where they close
- One-idea-per-video or listicle? Payoff placement (front-loaded / end-loaded / drip)
- Pacing markers: cut frequency, b-roll/screen-capture ratio, captions/subtitles style
- Loop design: does the ending feed back into the start (rewatch bait)?

### 4. Value proposition
- What does the viewer walk away with? (skill, tool name, workflow, emotion, identity boost)
- Practical value class: copyable workflow / tool discovery / news / entertainment / aspiration
- Specificity level (exact prompts & settings shown vs vague gesturing)

### 5. Psychology scoring (against 03_virality_science.md checklist)
- STEPPS scan: which of Social currency / Triggers / Emotion / Public / Practical value / Story
  are activated, and HOW (cite the moment)
- Primary emotion + arousal level (awe / amusement / FOMO-anxiety / anger / calm-useful)
- Identity-signaling share motive: who shares this and what does sharing say about them?
- Save/send trigger: what makes this savable or DM-able? (algorithmic gold per Mosseri)

### 6. CTA & funnel mechanics
- Explicit CTA (comment keyword → ManyChat DM? follow-for-part-2? link-in-bio? none?)
- Comment-bait mechanics; visible engagement loops in top comments if observable
- Where this video sits in the creator's funnel (top-of-funnel viral bait vs nurture vs sales)

### 7. Replicability verdict
- The extractable TEMPLATE: 3-6 bullet formula another creator could reuse
- What is commodity vs what is this creator's unfair advantage in this video
- Estimated difficulty for Tangent to execute this format (LOW/MED/HIGH + why)

### 8. Why it won (or lost) — analyst synthesis
- 3-6 sentences: the single most load-bearing reason for outlier performance, secondary factors,
  and any luck/timing components (trend-surfing, news cycle, platform push)
- If comparing against the creator's WORST performers: name the delta explicitly
