## Typography: Pricedown status (NOT installed)
- **Not downloaded.** typodermicfonts.com returns HTTP 406 to non-browser clients (both the Pricedown page and the free-pack ZIP), and sending a spoofed browser user-agent was refused by this session's permission policy. So the slides currently use the fallback headline face, **Anton** (our house display font, Google Fonts), with the specified treatment: white fill, thick black outline, drop shadow; B lines in #ffd166 with outline.
- **Licence, as read from the official site on 2026-11-18** (`https://typodermicfonts.com/license/`, `/pricedown/`, `/desktop/`; I did not read the EULA PDF itself):
  - The Pricedown page's only "Get the font" links are paid (MyFonts, Font Bros). It says "Desktop licenses cover print, logos, and static graphics." I could **not confirm Pricedown is in the free desktop pack** (`assets/downloads/typodermic-free-fonts-2026i.zip`; not opened).
  - The Desktop EULA covers "Commercial and non-commercial finished artwork containing no font software" incl. "Logos, branding, advertising, social-media graphics". It forbids redistribution (incl. giving the font to another person), embedding, modification, and use of the font/rendered glyphs to train AI. **Licensed user = one natural person.**
  - So rendered carousel PNGs are permitted use, *but* the licence must be held by the person using it. Recommendation: **Sparsh downloads/buys Pricedown himself** (free pack if it's in there, else a MyFonts/Font Bros desktop licence) and drops the `.otf` into `productions/2026-11-gta6-mens-day/fonts/` (git-ignored; never commit it). Then `node optB/build.mjs` picks it up automatically.
- **Brand flag:** `STYLE-REFERENCE.md` says *not* to use GTA's signature font; this task overrides that. Pricedown is Typodermic's font (licensed separately from Rockstar), so it's a licence question, not a trademark one, but it is the most "GTA" signal on the slides: worth a conscious yes from Sparsh/brand-director.
- **If Pricedown is swapped in:** it is wider than Anton. Re-render and re-check slide 1 (headline must clear his head at ~227 px), slide 2 (headline + stars on one row) and slide 6 (`white-space:nowrap` headline).
