**IDENTITY** (final; round 1 said "(at 22: light stubble only)" in the bracket):
```
IDENTITY (must match the first reference): South Asian Indian, warm brown skin, thick straight eyebrows, the same nose and slightly oval face, a small mole on the left cheekbone, side-parted wavy black hair. As an adult he has a short trimmed beard (at 22 he is clean-shaven or has faint stubble, no beard).
```
**FACES:**
```
FACES: semi-realistic like official AAA open-world game key art: realistic adult and child facial proportions, normal-sized natural eyes, defined jaw and cheekbones, real nose and lip structure, subtle skin texture, painterly airbrushed volume with crisp cel-shaded planes, clean outlines, sunset rim light. NOT cartoon, NOT Pixar or animated-film style, NOT big round eyes, NOT caricature, NOT a webcomic. Screens show only abstract colour shapes (no UI, no text). No posters with writing, no signs, no logos anywhere.
```

## Typography: Pricedown Black licence check (2026-11-18)
- **Source:** downloaded from Typodermic's official site (typodermicfonts.com → Downloads → "Free desktop fonts", package `typodermic-free-fonts-2026i.zip`). The file is `Pricedown Bl.otf`, stored as `../../fonts/PricedownBl.otf`. That folder is git-ignored, so the font is never committed or shared.
- **Bundled licence:** "Typodermic Font Software for Desktop End User License Agreement", v260817, effective 2026-08-17. What it says:
  - §2.2 lets a Licensed Desktop User "create, edit, view, print, and distribute materials for commercial or non-commercial purposes". The conditions: the distributed materials do not contain the Font Software, and the typeface appears only as fixed artwork, not as individually addressable glyphs. It names "images" and "rendered audiovisual content" as permitted finished materials.
  - §3.2: no volume limit. §3.1: one licensed desktop user unless stated otherwise (Sparsh).
  - §4.1/4.3: no redistribution or embedding (web, apps, templates, servers, image generators).
  - §4.4: no installing on a server or shared location "from which it can be accessed or synchronized for Use".
  - §4.7: no use of the font or its rendered glyphs to develop, train or fine-tune an AI model. Ordinary use of software with an AI feature is allowed if it gives the model no font data or training material.
- **Conclusion:** rendered PNG carousel slides for an Instagram ad/post are permitted finished materials (§2.2). We ship only flattened PNGs, so we proceed.
- **Caveat to note (my reading, not legal advice):** §2.1 ties installation to a "Workstation" (a desktop or laptop), and the definition excludes servers. These slides were rendered in a private, single-user, ephemeral cloud container. It is not shared and not a font source anyone can sync from (the concern of §4.4), but it is not literally Sparsh's laptop either. For the cleanest compliance, Sparsh can re-run `node build.mjs` on his own computer with his own copy of the font before posting. The output will be identical.
- I reviewed the rendered slides visually for QA. That is not development or training of a model, and the lettering was never sent to the image model.
- **Brand note:** `../../STYLE-REFERENCE.md` (earlier) said to avoid GTA's signature font and use Anton. `carousel.md` and this task chose Pricedown. Pricedown is Typodermic's typeface (not Rockstar's logo), and no GTA logo, wordmark or "VI" appears. The closer GTA association is a G3 brand-review point, not something I decided here.
- **Legibility call:** Pricedown's "1" reads as "I" at B-line size ("12" → "IZ", "11 p.m." → "II p.m." in the first render). So the B lines on slides 2-6 are Inter 800, yellow #ffd166, with a black outline. Headlines and the cover's second line stay in Pricedown.
