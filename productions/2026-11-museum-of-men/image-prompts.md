# Image prompts: The Museum of Men (Nano Banana Pro / Gemini image, 4:5)

Every slide uses the same set so the carousel reads as one museum. Paste the BASE text, then the
slide's subject line. Generate at 4:5 vertical (1080×1350). Keep the top ~40% as empty wall:
the headline is set there later in code (Fraunces), along with the small "Exhibit N" label card.

**BASE:** Photorealistic photograph inside a minimalist contemporary art museum. Clean warm-white
walls, pale grey polished concrete floor. One object displayed alone on a plain white rectangular
plinth in the lower centre of the frame. A single soft warm spotlight from above, gentle natural
shadow. The upper 40% of the frame is empty white wall. Eye-level camera, 50mm lens, shallow
depth of field, calm and premium, like a museum catalogue photo. The object is an ordinary
Indian household item with realistic wear. No people, no text, no logos, no brand names, no
signage.
