## Steps (LinkedIn app)
1. Tap **Post** → the media/video icon → pick `museum-of-men-v2-4x5.mp4`.
2. Paste the caption. Visibility: **Anyone**.
3. Optional:
   - **Thumbnail:** choose the opening title frame if the app offers it. If not, the default is fine.
   - **Subtitles:** none needed. The video has no speech, and all its text is on screen.
4. Post. Then send Claude the post link.

## Do / don't
- **Do:** reply to comments in the first hour or two, briefly and in your own voice.
- **Don't:**
  - add "Agree?" or "Comment YES" style lines; LinkedIn demotes engagement bait;
  - put the YouTube link in the post;
  - tag the AI companies in this post. It's a personal story, and tags make it read like an ad.
- **Optional:** drop the YouTube link in a comment later, only if someone asks where else it lives.

## Timing
Late morning to lunchtime IST on a weekday is a common good slot. That is practitioner wisdom, not our own data yet.
